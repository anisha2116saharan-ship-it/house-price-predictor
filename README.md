# House Price Prediction System

An interactive Machine Learning web application predicting residential property prices using regression algorithms.

## Project Overview
* **Domain:** Real Estate / Predictive Econometrics
* **Algorithm:** Random Forest Regressor
* **Dataset:** California Housing Dataset (Scikit-Learn)
* **Framework:** Streamlit, Scikit-Learn, Pandas, NumPy

## Features
* Parameter input controls for structural and regional demographic variables.
* Instant valuation calculations using non-linear ensemble trees.
* Web-ready interface powered by Streamlit Cloud.
